# HireIT - Job Portal Website

## Overview
HireIT is a modern job portal platform designed to connect job seekers with employers. Our platform provides an efficient and user-friendly way to browse, post, and apply for jobs.

## Features
- **Job Listings**: Browse thousands of job postings from various industries
- **Job Search**: Advanced search filters to find the perfect job match
- **User Profiles**: Create and manage professional profiles
- **Application Tracking**: Track your job applications in real-time
- **Employer Dashboard**: Post job openings and manage applications
- **Notifications**: Get alerts for new job matches

## Tech Stack
- **Frontend**: NextJS
- **Backend**: PHP Laravel
- **Database**: PostgreSQL
